## AI 助学中心（AI Study Hub）本地版搭建

在 `C:\Users\gps35\AI-study-hub` 从零搭建了一个 AI 助学网站，已本地跑通（含构建验证）。

**架构（用户要求：终端用户无需自带 Key → 必须后端代理）**
- 前端：React + Vite。文件解析 PDF(pdfjs-dist)、docx(mammoth)、图片(tesseract.js OCR)、md/txt；存储用 idb-keyval(IndexedDB)；状态 zustand。
- 后端：Express 代理 OpenAI 兼容接口（默认 OpenRouter，支持 SSE 流式）。Key 仅存服务端 `.env`，浏览器调同源 `/api/chat`，无 CORS/暴露问题。
- 流程：文档库上传 → AI 生成(速查表/练习题/摘要) → 阅读器划重点 & 引用提问。

**关键决策/坑**
- pdf.js worker 用 `import workerUrl from 'pdfjs-dist/build/pdf.worker.min.mjs?url'` 让 Vite 处理，已正确拆分为独立 chunk。
- tesseract.js 用动态 `import()` 按需加载，避免拖慢首屏；OCR 首用需联网下载语言包。
- SSE：后端 `fetch` 上游后用 `res.write()` 透传 `data:` 行；前端用 `res.body.getReader()` 逐行解析 `[DONE]`。
- 阅读器高亮用 Selection API + TreeWalker 计算块内字符偏移，标注存 blockId+start+end。

**运行**：`npm install` → 复制 `.env.example` 为 `.env` 填 Key → `npm run dev`（前端5173+后端8787）；发布用 `npm run build && npm start`（后端托管 dist）。

**待办**：用户需自行填入真实 AI_API_KEY 才能跑通生成/问答；发布到纯静态平台不行（需 Node），需 Render/VPS 等。
